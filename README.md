# Priority Queue in C

A menu-driven priority queue implementation
using arrays and structures in C.

## Features
- Insert an element with priority
- Delete highest-priority element
- Peek at highest-priority element
- Display queue elements

## Priority Rule
Smaller priority number = Higher priority.

Elements with equal priority are processed
in insertion order.

## Concepts Used
- Arrays
- Structures
- Priority Queue
- Linear Search

## How to Run

Compile:
gcc priority_queue.c -o priority_queue

Run on Windows:
.\priority_queue.exe

## Language
C
